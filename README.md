# Advanced_programming_project
MATRICOLA: 246031
Progetto programmazione avanzata.
Implementazione di un algoritmo che si occupi della gestione di un'autoconcessionaria con reparti negozio, noleggio ed officina.
La parte principale del programma riguarderà la compravendita di veicoli, sia nuovi che usati, con gestione di un parco auto.
Un'altra parte del codice sarà dedicata alla gestione del noleggio di una gamma di macchine in possesso. 
L'autoconcessionaria fornirà assistenza ai clienti tramite officina, che dovrà anche occuparsi della riparazione delle macchine destinate sia alla rivendita che al noleggio.


Compiler: std=c++11
